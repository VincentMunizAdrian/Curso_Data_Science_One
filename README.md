# Curso_Data_Science_One

# 📊 Análisis de Depresión en Estudiantes de la India  

Este proyecto forma parte del curso de **Data Science** de CODERHOUSE y tiene como objetivo analizar los factores que pueden influir en los niveles de depresión de estudiantes universitarios en la India.  

Se utilizan técnicas de **Machine Learning** y visualización de datos para identificar patrones en variables demográficas, académicas, laborales y generales que podrían estar relacionadas con la salud mental de los estudiantes.
